# Артефакты практики 21

Воспроизводимый учебный пакет; если использовался demo, данные синтетические.

- manifest.json: происхождение данных, ограничения, протокол и версии.
- split_membership.csv: ID, время и классы по частям.
- preprocessor.joblib: предобработка; загружать только из доверенного архива.
- mlp_state.pt + model_config.json: веса и архитектура PyTorch.
- experiments.csv: все прогоны, seed, время и метрики.
- validation_predictions.csv: результаты только для validation.
- inference_samples.csv: эталонные примеры для восстановления модели.
- selected_history.csv: train/validation потери по эпохам.

Тестовая часть НЕ оценивалась в практике № 21. Промышленное внедрение требует реальных данных, независимого периода, мониторинга, SLA и подтверждения экономической модели.
