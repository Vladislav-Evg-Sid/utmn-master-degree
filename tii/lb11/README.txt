ЗАПУСК
1. Откройте блокнот 11_student.ipynb или 12_student.ipynb в Google Colab.
2. Загрузите orders_dirty.csv (рабочий учебный набор преподавателя; не входит в комплект).
3. Если сохранился split_ids_06.csv из занятия 6, загрузите его в ту же директорию.
4. Выполните Runtime -> Restart session and run all.
5. Экспортируйте результаты, указанные в методических указаниях, и подготовьте отчёт.

ВАЖНО
- Исходные данные преподавателя НЕ заменяются искусственными цифрами или демонстрационным примером.
- При смене набора данных со 121 на 600 записей старый split_ids_06.csv может не подойти.
- Блокноты создают tyumgu_feature_rules.py во время запуска.
- test не используется для выбора; если изучался в предыдущей работе, финальная оценка уже не независима.
- Стоимости FP=200 ₽, FN=2000 ₽ — учебные допущения.
- Предполагаются версии scikit-learn >=1.3, pandas >=2.0.
