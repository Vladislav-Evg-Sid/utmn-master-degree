## Локальное окружение

В корне проекта находится изолированное окружение `.venv` с Python 3.12.14.
В VS Code выберите интерпретатор `.venv/Scripts/python.exe` для ноутбука.
Для повторного выполнения из корня репозитория:

```powershell
& .\.venv\Scripts\python.exe .\tii\lb7\run_notebook.py
```

Для восстановления окружения с установленным Python 3.12:

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r tii/lb7/requirements.txt
& .\.venv\Scripts\python.exe tii/lb7/run_notebook.py
```

Скрипт регистрирует ядро внутри окружения запустившего его Python и выполняет ноутбук в его папке.
При ручном запуске рабочая папка должна быть `tii/lb7`.
