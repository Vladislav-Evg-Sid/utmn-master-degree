- Методические_указания_17.docx / .pdf: DBSCAN и агломеративная кластеризация.

- demo_orders_17_18.csv: исключительно демонстрационный синтетический набор

- illustrations/: дополнительные изображения, уже встроенные в Word/PDF.
- requirements.txt: необходимые Python-библиотеки.

ПОРЯДОК ЗАПУСКА GOOGLE COLAB
1. Откройте https://colab.research.google.com/ и выберите «Загрузить блокнот».
2. Загрузите 17_student.ipynb или 18_student.ipynb.
3. В панели «Файлы» загрузите orders_dirty.csv, выданный на предыдущих практиках,
   или demo_orders_17_18.csv только для проверки работы кода. Файл должен лежать в
   текущем рабочем каталоге блокнота.
4. Выполните Runtime / Restart session and run all (Среда выполнения — перезапуск и запуск всех).
5. Сохраните результат .ipynb и сформированные CSV для отчёта.
6. Если библиотек нет, установите: pip install -r requirements.txt; в стандартном Colab
   обычно эти зависимости доступны без дополнительной установки.

ВАЖНО
- На занятии 17 кластеризация заказов выполняется только по distance_km,
  queue_size, promised_minutes. late, actual_minutes, order_id исключаются из X.
- Для DBSCAN без штатного predict в блокноте показан лишь иллюстративный способ
  приблизительного присвоения новых объектов ближайшей ядровой точке.
- На занятии 18 Wine (178 строк, 13 признаков) — учебный набор sklearn. Его целевые
  метки допустимы только для post-hoc анализа и не используются при fit PCA/K-means.
- Все параметры imputer/scaler/PCA подбираются по dev/train без использования holdout/test.
- Для 17 и 18 занятия предусмотрен отдельный отчет (2–4 страницы каждый)
  по перечням в методических указаниях; критерии — по 10 баллов.

Проверка в рабочей среде: запуск всех вычислительных ячеек на демонстрационных
наборах со 121, 361 и 600 строками. Это проверка исполнимости, не подтверждение
качества кластеризации на реальных заказах.
