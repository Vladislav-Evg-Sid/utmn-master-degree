# Лабораторная работа 8

Выполнены задания методички и шесть самостоятельных заданий ноутбука.
Состав, типы и порядок исходных 13 ячеек сохранены.

## Запуск

Используется существующее окружение `.venv` в корне проекта, Python 3.12.14.
Из корня репозитория:

```powershell
& .\.venv\Scripts\python.exe .\tii\lb8\run_notebook.py
& .\.venv\Scripts\python.exe .\tii\lb8\verify_saved.py
```

Первый скрипт запускает все ячейки в новом ядре и сохраняет выводы.
Второй загружает созданные здесь доверенные joblib и проверяет преобразование
validation, вероятности и классы в отдельном процессе.
При ручном запуске выберите корневую `.venv` как ядро; рабочая папка — `tii/lb8`.

Для восстановления окружения из корня проекта:

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r tii/lb8/requirements.txt
& .\.venv\Scripts\python.exe tii/lb8/run_notebook.py
```
